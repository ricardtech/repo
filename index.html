Instalação via Repositório Pacman (x86_64)

Receba atualizações automáticas do Play Max via pacman -Syu.

1

Instalação Automática em 1 Linha (Recomendado)

Adiciona o repositório oficial ao /etc/pacman.conf e instala o aplicativo:

echo -e "\n[playmax]\nSigLevel = Optional TrustAll\nServer = https://repo.rictv.top/\$arch" | sudo tee -a /etc/pacman.conf && sudo pacman -Sy rp-play-max-linux
2

Ou Atualização Manual

Se o repositório já estiver configurado, basta sincronizar e atualizar:

sudo pacman -Syu rp-play-max-linux

Instalação para Distribuições baseadas em Debian / Ubuntu

Instale o pacote binário .deb oficial diretamente no seu sistema.

1

Baixe o pacote .deb oficial

Utilize o terminal para baixar a versão mais recente:

wget https://repo.rictv.top/rp-play-max-linux_2.4.1_amd64.deb
2

Instale via APT / dpkg

Resolva as dependências e registre no menu de aplicativos:

sudo apt install ./rp-play-max-linux_2.4.1_amd64.deb

Execução Universal via AppImage
