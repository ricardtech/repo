Repositório Oficial de Pacotes para Arch Linux, Manjaro, BigLinux e derivados

1 Instalação Rápida Recomendado

Adicione o repositório e instale o Play Max com um único comando no terminal:

echo -e "\n[playmax]\nSigLevel = Optional TrustAll\nServer = https://repo.rictv.top/\$arch" | sudo tee -a /etc/pacman.conf && sudo pacman -Sy rp-play-max-linux
2 Instalação Manual (Passo a Passo)

Caso prefira editar manualmente, adicione ao final de /etc/pacman.conf:

[playmax] SigLevel = Optional TrustAll Server = https://repo.rictv.top/$arch

Depois, sincronize e instale o pacote oficial:

sudo pacman -Sy rp-play-max-linux
3 Instalação via Interface Gráfica

Após adicionar o repositório, você também pode abrir a Central de Aplicativos (Pamac / Big Store / Octopi), pesquisar por Play Max e clicar em Instalar para receber atualizações automáticas do sistema.
