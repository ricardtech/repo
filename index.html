Play Max Linux

Repositório de pacotes e distribuição nativa para distribuições Linux Desktop e Notebook.

1Instalação Rápida (1 Comando)Recomendado

Adiciona o repositório oficial [playmax] ao pacman e instala o aplicativo automaticamente:

echo -e "\n[playmax]\nSigLevel = Optional TrustAll\nServer = https://repo.rictv.top/\$arch" | sudo tee -a /etc/pacman.conf && sudo pacman -Sy rp-play-max-linux
2Instalação via Loja Gráfica (Pamac / Big Store)

Após adicionar o repositório, abra a Central de Aplicativos do seu sistema, pesquise por Play Max e clique em Instalar para receber todas as atualizações automaticamente.

1Instalação do Pacote .debDebian / Ubuntu

Baixe e instale o pacote nativo para Debian, Ubuntu, Linux Mint, Pop!_OS e Zorin OS:

wget https://repo.rictv.top/x86_64/rp-play-max-linux_2.2.2_amd64.deb -O rp-play-max.deb && sudo apt install -y ./rp-play-max.deb
1Execução Portátil (AppImage)Todas as Distros

Não precisa instalar dependências no sistema. Basta baixar, dar permissão de execução e abrir:

wget "https://repo.rictv.top/x86_64/RP%20-%20Play%20Max-2.2.2.AppImage" -O "Play-Max.AppImage" && chmod +x "Play-Max.AppImage" && ./"Play-Max.AppImage"
